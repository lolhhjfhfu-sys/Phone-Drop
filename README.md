# Phone Drop

Игра для Telegram Mini App: открываешь кейсы и выбиваешь телефоны разной редкости. Всё в одном файле `phone-drop.html`, без сборки и зависимостей.

## Возможности

- **Кейсы**: «Старт» (150), «Про» (600), «Элит» (2000). Чем дороже кейс, тем выше шанс на редкие телефоны. Рулетка с плавной анимацией.
- **33 телефона** в четырёх редкостях: Редкий, Эпик, Легендарный, Абсолют. Каждый нарисован в SVG со своим блоком камер и логотипом.
- **Цвет и память**: при выпадении телефон получает случайный цвет и объём памяти. Память влияет на цену продажи.
- **Аксессуары**: 7 чехлов, которые покупаются и надеваются на конкретный телефон прямо в коллекции.
- **Задания**: 6 ежедневных заданий с наградой.
- **Календарь**: 7 дней наград, серия сбрасывается при пропуске.
- **Промокоды** и бонус раз в 4 часа (вкладка «Ещё»).
- **Админ-панель** (вкладка «Ещё»): выдача монет и телефонов, выбор редкости следующего дропа, создание промокодов, сброс заданий.
- Интеграция с Telegram: имя игрока, тёмная тема, вибрация.

## Запуск в Telegram

1. Выложи `phone-drop.html` на хостинг с https (GitHub Pages, Netlify, Vercel, свой сервер). Файл можно переименовать в `index.html`.
2. Добавь в `<head>` скрипт Telegram:
   ```html
   <script src="https://telegram.org/js/telegram-web-app.js"></script>
   ```
3. Создай бота у [@BotFather](https://t.me/BotFather): `/newbot`.
4. Привяжи мини-приложение: `/newapp`, укажи ссылку на свой хостинг.
5. Открой бота и запусти приложение.

Для проверки без Telegram достаточно открыть файл в браузере. Игра работает и так, просто без имени игрока и вибрации.

## Промокоды

Встроенные коды работают один раз на устройство:

| Код | Награда |
|---|---|
| `START` | 777 монет |
| `DROP` | 1500 монет |
| `LEGEND` | случайный легендарный телефон |
| `ABSOLUT` | случайный телефон редкости Абсолют |

Свои коды создаются в админ-панели: код, монеты и при желании телефон нужной редкости.

## Админ-панель

Открывается во вкладке «Ещё» по паролю. В коде хранится только SHA-256 хэш пароля (константа `AH`), а не сам пароль.

Чтобы сменить пароль:

```bash
echo -n "НОВЫЙ_ПАРОЛЬ" | sha256sum
```

Полученный хэш подставь в константу `AH` в конце скрипта.

> **Важно.** Игра хранит данные только на устройстве игрока, а проверка пароля идёт в браузере. Любой, кто откроет код, сможет включить админку на своём устройстве. Админ-панель меняет только локальные данные и не может выдать что-то другому игроку. Для настоящей админки и общего баланса нужен сервер.

## Хранение данных

Прогресс лежит в `localStorage` под ключом `pdrop`: монеты, телефоны, чехлы, задания, календарь, использованные промокоды. Если очистить данные Telegram или браузера, прогресс пропадёт.

## Как изменить игру

Все данные лежат в начале скрипта массивами и константами.

**Добавить телефон** в массив `P`:

```js
['id','Название','rare',['#цвет1','#цвет2'],'камера','БРЕНД']
```

Редкость: `rare`, `epic`, `legend`, `abs`. Для Apple бренд пиши `'A'`, тогда нарисуется логотип-яблоко. Вид камеры выбирается из значений:

| Значение | Вид |
|---|---|
| `one` | одна линза |
| `diag` | две линзы по диагонали (iPhone 13) |
| `tri` | три линзы треугольником (iPhone Pro) |
| `bar` | три линзы горизонтальной полосой |
| `v3`, `v4` | линзы столбиком (Samsung) |
| `sq` | квадратный блок 2×2 |
| `pill` | горизонтальная капсула |
| `cap` | вертикальная капсула |
| `circ` | большой круглый блок |
| `tl` | круглый блок в левом верхнем углу |
| `ring` | круг с крупной линзой |
| `gly` | стеклянная спина (Nothing) |
| `rug` | защищённый корпус |
| `duo` | складной телефон из двух половин |

**Кейсы** задаются в массиве `C`: цена, цвет и шансы по редкостям (в сумме 100).

**Чехлы** задаются в массиве `K`: идентификатор, название, цена, цвет заливки, прозрачность, цвет рамки.

**Награды календаря** в массиве `CAL`, **задания** в массиве `T`, **цвета корпуса** в `COL`, **варианты памяти** в `MEM`, **промокоды** в `PR`.
